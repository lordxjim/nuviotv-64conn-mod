# nuviotv-64conn-mod
面向 NuvioMedia/NuvioTV（官方 Android TV 客户端，基线 commit 48d6449），给出将其 HTTP 并行下载引擎的并行连接数上限从 16（需性能模式）/ 4 （普通模式）扩展到 64 的完整改造。

改造遵循三条原则。其一， 单一事实源：新增一个常量
MAX_PARALLEL_CONNECTION_COUNT_NATIVE_MEMORY = 64，读钳制、两处写钳制、
UI 滑块上限四处引用同一常量，消除原先散落的 3 处字面量 16，未来调参只改一行。
其二，默认行为零变化：默认连接数仍为 2 且默认关闭并行，普通模式上限仍为 4，
64 路仅在用户显式开启 ExoPlayer Native Memory（性能模式）后可达。其三，升并
发必须伴随容量与内存联动：执行线程池核心 32 升至 80、OkHttp 连接池空闲上限
32 升至 128、Dispatcher 限额升至 128，并新增引擎侧分块护栏，保证 64 路 × 大分块
组合不会突破设备的原生内存预算。

针对避免被标记限速与拒绝服务的目标，改造保留了引擎原有且与 aria2 基准一
致的 429/503 保险丝（深度减半 + 指数静默 + 逐级恢复）、Retry-After 遵循与
HTTP/1.1 钉死策略，将块级重试预算从 2 次提升到 4 次并加入随机抖动以消除重试惊
群，同时把播放链 User-Agent 从自称桌面 Chrome 的伪装串更换为带版本号的诚实播
放器身份。改动合计 8 个文件，+120 / −32 行，已通过四层一致性复核与全部关键不
变量的存在性检查。
